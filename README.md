# Правка

Android-приложение для правки надиктованного текста одним касанием — прямо в том
поле, где текст набран. Личное приложение одного владельца, без публикации в
Google Play. Полное ТЗ — в документе «Правка. ТЗ для Claude Code», версия 1.2.

Внутри живёт второй режим — **«Засечка»**, голосовой таймшит на том же движке
распознавания: вторая плавающая кнопка «З», тап → наговорил, чем
занят → тап. Обе кнопки видны всегда: «П» больше не следит за текстовыми
полями (и служба вообще не подписана на оконные события — складыванию легче);
без поля под курсором результат правки уезжает в буфер и уведомление.
Сонет раскладывает фразу в запись с категорией и клиентом; конец предыдущего
дела = начало нового. Вкладка «Засечка» —
лента дня, правка записей, итоги по категориям и клиентам за день/неделю.
Дело, которое автоматика порезала (звонок, YouTube), лента показывает одним
блоком: высокая линия на весь период, рядом чистое Σ-время, прерывания —
параллельными строками внутри; правка/крестик блока действуют на все куски.
Голосом правится и время («еда была с 16:43 до 17:40») — правка и удаление
голосом действуют на всё разрезанное дело целиком, как ✎/✕ блока. Любую свою
операцию (запись, правку, удаление) можно откатить: «↩︎ Отменить …» рядом с
переключателем День/Неделя и в меню долгого нажатия кнопки «З» — лента возвращается ровно в
то состояние, что было до операции (пять шагов в памяти).
У каждой категории два своих числа (Настройки → Категории, тап по строке):
базовое время — сколько такое дело обычно длится, и ценность часа от −10 до
+10. Дело, пережившее своё базовое время, заставляет кнопку моргнуть и
спросить «Всё ещё «Обед»?»: «Да» — считаем дальше, «Нет» — сразу новая
запись; тумблер «Спрашивать «всё ещё …?»» выключает это целиком. Ценность
складывается в балл дня (часы × ценность) — он стоит прямо под датой радужной
полоской: дорожка от нуля вправо через синий, зелёный и жёлтый к красному,
до которого надо дотянуться (сотня очков за день), яркая заливка показывает,
докуда дошёл; ушедший в минус день заливает короткую фиолетовую полосу слева
от нуля. Свои очки показывает и каждая строка ленты.
Цвета категорий — радуга по эффективности часа: работа и чтение красные,
спорт оранжевый, люди зелёные, сон и логистика голубые, отдых фиолетовый,
«Потери» — самый глубокий фиолетовый на дне. Потери — категория-автомат:
пять минут тишины после конца последнего дела — и в ленте открыто тикают
живые «потери», пока не надиктуешь настоящее дело (янтарный пульс кнопки
при этом продолжает звать). Закрытая дыра между делами ≥5 минут становится
записью «потери» после 45-минутного карантина (окно для ретро-диктовки);
авто-YouTube падает туда же. Настоящая запись поверх потерь вычитается из
них мгновенно — потери обнимают дело с двух сторон, крошки короче 5 минут
исчезают. Удалять потери бесполезно по замыслу — неназванное время
отрастает обратно; выход один: назвать его делом.
Кнопка сама напоминает о дырах во времени (пульс + уведомление), утром
спрашивает «день начался?», вечером — «закрыть день?». Записи зеркалируются в
Google Sheets через Apps Script-вебхук — настройка в
[docs/zasechka-sheets.md](docs/zasechka-sheets.md). (Зеркало в Notion было и
удалено по решению владельца — Sheets остался единственным зеркалом.)

Данные держатся на трёх опорах. Раз в час на диск снимается копия всего
незаменимого — лента, словарь, правила Правки, телефонный слой: каждый час за
последние двое суток и последний час каждого дня за месяц. Лента вдобавок
копируется раз в день и перед любым резким сокращением записей, а список копий
с кнопками «Восстановить»/«Файлом» лежит в Настройках Засечки. И третья опора —
дорога назад из выгрузки: «Импорт CSV» поднимает ленту из любого
экспортированного файла (уже имеющиеся строки не удваиваются, безымянные
«потери» лента отращивает сама). Сами файлы пишутся атомарно и с fsync,
предыдущая версия остаётся рядом (`.prev`), а запись пустой ленты поверх файла
с записями отклоняется — стереть всё сразу лента не умеет, значит это баг.

У Засечки есть и телефонный слой (доступ к статистике использования +
журнал звонков): отдельно от ленты считаются экранное время, минуты по
приложениям, подъёмы телефона и «отвлечения» (взял-глянул-убрал быстрее
2 минут). Два исключения сами попадают в ленту как прерывания: «пожиратели
внимания» (YouTube и кто ещё будет назначен тапом по приложению) и звонки
≥1 минуты. Оба режут текущее дело, и оно продолжается после них
автоматически; если активного дела нет, пожиратель ложится просто своей
строкой («Отдых»).

Таймеры переживают обновление APK: дедлайн помидора хранится
на диске, служба перезапускается сама, идущее дело лежит в файле;
помидор, дозревший во время установки, дозасчитывается с уведомлением.
(Подглядывание за адресной строкой Chrome — «Сайты в Chrome» — удалено:
опрос дерева чужого окна коррелировал с чернотой при складывании.)

Автоматика ленты этим не ограничивается: сон определяется по экрану
(самый длинный ночной разрыв «погас—включился» ≥3 ч становится записью
«Сон» и заодно закрывает вечернее дело), тренировки подтягиваются из
intervals.icu (athlete id + API key в настройках Засечки; бег/вело/силовая/
ходьба ложатся в свои категории, Garmin-длительность и счёт сна дописываются
к записи «сон»). На кнопке «З» живут помидоры: долгое нажатие → 🍅 25/50 или
перерыв 5; кнопка превращается в счётчик минут, готовый помидор вибрирует,
предлагает перерыв и записывается на текущее дело (🍅×N в ленте). Правило
всех авто-вставок: ручная запись сильнее автоматики, но лента никогда не
пересекается — день складывается ровно в 24 часа (аудиторское правило
владельца). Ретро-заявление («обедаю с 16:43», сказано в 16:53) режется
вокруг уже записанных авто-фактов: YouTube 16:43–16:50 остаётся прерыванием,
блок обеда показывает его параллельной строкой, а чистое время еды считается
за вычетом. Авто-запись, задетая краем, подрезается до начала ручной. При
загрузке лента чинит и старые наложения тем же расщеплением.

Третий режим — вкладка **«Дела»**: список задач Todoist прямо в приложении.
Доступ прямой, личным API-токеном (Todoist → Настройки → Интеграции →
Разработчик), без посредников и OAuth — токен живёт только на телефоне; Засечка
понимает и новый /api/v1, и прежний /rest/v2 (выясняет один раз, какой отвечает).
Группы: «Сегодня» (вместе с просроченным) раскрыта, «Без даты и без проекта»
и проекты свёрнуты, сверху поиск по вхождению слова. Тап по делу — оно
становится текущей записью ленты: название берётся из Todoist буква в букву,
категория — из собственной истории этого дела, а если такого ещё не было,
её подбирает Сонет. Когда запись закрылась, в задачу уезжает коммент со
временем: «⏱ 22 августа, 19:30–20:42 · 1 ч 12 м». Список кэшируется на диск,
поэтому вкладка открывается мгновенно и без сети. Добавление дел в Todoist —
вторая часть, её пока нет.

**Целевое устройство:** Google Pixel 10 Pro Fold, Android 16.
**Стек:** Kotlin, Jetpack Compose (Material 3), Gradle Kotlin DSL.

## Первая настройка на новой машине

1. Установи JDK 17+ и Android SDK (проще всего через Android Studio).
2. Скопируй `local.properties.example` в `local.properties`, поправь `sdk.dir`.
3. Всё. Пароли keystore уже прописаны как значения по умолчанию.

## Подпись — важно

Единый keystore `keystore/pravka.jks` лежит в репозитории и используется для
**всех** сборок, включая debug. Никогда не подписывай другим ключом: установка
поверх сломается, и вместе с приложением сотрётся накопленный словарь,
настройки и включённая служба доступности.

- Пароль хранилища и ключа: `pravka-keystore-2026`
- Алиас: `pravka`
- SHA-256 отпечаток: `B9:E9:79:F0:2C:F2:9D:EB:35:3D:CF:2B:CE:99:C5:FC:64:E5:1A:33:27:24:CB:B6:5C:53:28:25:64:53:11:B5`

## Версии сборок

`version.properties` хранит счётчик `buildNumber`. Каждый запуск
`assemble*` / `install*` / `deliver*` увеличивает его на 1.
`versionCode = buildNumber`, `versionName = 2.0.<buildNumber>`.
Файл коммитится, чтобы номера не повторялись между машинами.

## Сборка и доставка

```powershell
.\gradlew assembleDebug    # просто собрать APK
.\gradlew installDebug     # собрать и поставить по adb
.\gradlew deliverApk       # собрать и отправить APK в Telegram
.\gradlew deliver          # собрать + adb-установка (если устройство видно) + Telegram
```

APK лежит в `app/build/outputs/apk/debug/app-debug.apk`.

### Канал 1: adb по Wi-Fi

Один раз: на телефоне включи «Отладку по Wi-Fi» (Настройки → Система →
Параметры разработчика → Беспроводная отладка) и спарь компьютер:

```powershell
.\scripts\reconnect.ps1 -Pair 192.168.x.x:PORT -Code 123456   # ip:port и код с экрана сопряжения
.\scripts\reconnect.ps1 192.168.x.x:PORT                      # ip:port с главного экрана беспроводной отладки
```

Дальше каждый раз, когда adb отвалился (после каждой перезагрузки телефона):

```powershell
.\scripts\reconnect.ps1
```

### Канал 0: GitHub Actions (основной во время облачной разработки)

Каждый пуш в любую ветку собирает подписанный debug APK и кладёт его в ветку
`apk-builds` (файл `pravka-debug.apk` + `build-info.txt`). Для CI-сборок
`versionCode = номер запуска workflow`, поэтому каждая следующая сборка
ставится поверх предыдущей. Скачать можно также из вкладки Actions
(артефакт `pravka-debug-apk`).

### Канал 2: Telegram-бот

1. Создай бота через `@BotFather`, получи токен.
2. Узнай свой chat_id (например, через `@userinfobot`).
3. Впиши `telegram.botToken` и `telegram.chatId` в `local.properties`.
4. `.\gradlew deliver` — APK приедет в чат с версией, временем сборки и
   последним сообщением коммита. Тап по файлу → установить.

Если токен не заполнен, таска просто пишет «skipping Telegram delivery» и не
падает — сборка работает и без него.

## Quick Tap (настроится на этапе 4)

Жест «двойное касание по задней панели» настраивается вручную:
Настройки → Система → Жесты → Быстрое касание → действие «Открыть приложение».
Подробная инструкция появится в этом README на этапе 4.
