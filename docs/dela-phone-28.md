## Что поменялось на сервере

- **Флаг** `asks` в `features` синка и `/api/me`. Нет флага — всё как раньше.
- **Три ключа `payload` у вопроса** (`tasks.suggestions`, поле `suggestions` синка) — ставит сервер при записи, телефон
  ничего нового не шлёт:
  - `urgency` — `"today"` или `"evening"`; у `today` ещё `urgent_on` (ГГГГ-ММ-ДД по Москве). **Сгорает** —
    `urgency == "today"` И `urgent_on == сегодня` (сегодня — по Москве). Завтра тот же вопрос — обычный вечерний;
  - `about` — `{kind, id?, title}`: `client` (id проекта), `person` (id карточки или без id — только имя), `meeting` (id
    карточки встречи, если есть), `small`; у кандидата «Сейчас на завтра» — `plan`. Имя группы клиента и человека —
    свежее по `id` из синка (проекты, люди), `title` — запас. Вопрос без `about` (записан до выката) — мелочь
    (`title` — `batch_title` или «Прочее»), срочность — вечер.
- **Свод** — `asks.rhythm` (поля шага 1 `evening`, `fri`, `fri_winter`, `winter` и шага 2 `today` «15:00», `night_end`
  «05:00», `today_max` 5, `evening_max` 7) и новый ключ `day.quiet` (очереди нужна только часть `weekend`: `{dow: 5,
  from: "15:00"}` — с пятницы 15:00 до понедельника `night_end` тихо; `null` — тишины нет; `daily` — шаг 4 Засечки).
  Записи нет или поле кривое — заводское по полю, молча. Заводское — `svod` контракта (`factory`).
- **Вид** `GET /api/view/asks?at=` — фаза, ближайший заход, группы. Телефону он **не нужен**: всё считается из снимка
  синка (как веб) — так блок живёт и без сети.

## Что сделать на телефоне

1. **`core/Asks.kt` — новый, чистый (JVM-тесты):**
   - `FACTORY` (точная копия `svod.asks.rhythm.factory` контракта), `QUIET_FACTORY`; `rhythm(raw =
     Svod.value(Svod.ASKS_RHYTHM))` и `quiet(raw = Svod.value(Svod.DAY_QUIET))` — Свод поверх заводского по полю, как
     `asks.norm` / `norm_quiet` (ЧЧ:ММ, ММ-ДД — настоящий день, числа 1…50, `dow` 1…7, `weekend: null`);
   - `phase(nowMs, rh, q)` и `next(nowMs, rh, q)` → `{atMs, phase, label}` — ровно как `asks.phase` / `next_start` /
     `when_word` (порядок проверки — в `phases._` контракта; зона — `Europe/Moscow` явно, не зона телефона; вечерний и
     пятничный заход — как `asks.evening_at` шага 1); `label` — «15:00» сегодня, иначе «пн 15:00»;
   - `urgent(sg, today)`, `about(sg)` (с запасом для вопроса без `about`);
   - `queue(s, me, nowMs): Queue` — `phase, next, groups (kind, id, title, items, urgent), urgent, total, rest, plan,
     max(today, evening)`, порядок — как `asks.queue` (группы со сгорающим — первыми, дальше `client → person → meeting
     → small`, внутри вида — у кого самый старый вопрос; в группе — сгорающее, потом старые сверху); кандидаты плана —
     только числом (`DelaViews.asks` с шага 1 их уже не берёт). Без флага (`!s.asksOn`) — `Queue` «как раньше»: все
     ждущие, свежие сверху. `payload` разбирать один раз на вопрос (кэш по `id` + `rev`), не на каждой перерисовке;
   - `foldText(q)` — строка как `asksFoldText` веба: «Подскажи · к 15:00: 1 · к вечеру: 6» (нулевые части не пишутся),
     в пятницу до захода — «Подскажи · к 14:00: 7» (ближайший заход — вечерний: `next.phase == evening`), после
     «сгорающего» — «Подскажи · к вечеру: M», в тишине — «Подскажи: N — до понедельника тихо».
2. **`core/Dela.kt`** — `FEATURE_ASKS = "asks"`, `Snapshot.asksOn`; **`core/Svod.kt`** — `ASKS_RHYTHM = "asks.rhythm"`,
   `DAY_QUIET = "day.quiet"` (шаг 4 возьмёт эту же константу).
3. **`TodayV2.kt`** — `TodayV2Data.asks` → `queue: Asks.Queue` (собирается в `buildV2`, где сейчас `DelaViews.asks`;
   минутный тик `TodayBody` уже пересобирает данные — фаза сменится сама). `NewCard` — по фазе:
   - `before`, `quiet` и `today` без сгорающего — одна строка `foldText` (тап — `rememberSaveable` «раскрыто» до смены
     фазы: ключом — сама фаза);
   - `today` со сгорающим — только сгорающее (до `today_max`), подпись «сгорает сегодня», под ним строка «к вечеру: M»
     (тап — раскрыть всё);
   - `evening` или раскрыто — группами: строка группы `t.caption` «ООО Ромашка · 2» (сгорающее в группе — «· сгорает
     K»), строки вопроса прежние (Да / Ответить / Нет, варианты кнопками), до `evening_max` вопросов, дальше «ещё K — в
     «Новом»» (во вкладку Дел, как «все» сейчас);
   - строка шага 1 «Сейчас на завтра: предложено N…» остаётся последней. Обе раскладки (сложенный и разложенный) — один
     `NewCard`.
4. **Вкладка Дел «Новое» и операции — без изменений**: телефон ничего нового не шлёт.
5. **Fold**: на главном потоке — только сборка уже готового `Queue` (десятки строк); новых окон и сторов нет, `DataRoot`
