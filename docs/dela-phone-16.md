«Дела» на телефоне — ниже; сервер всё уже умеет, телефону — догнать экраны.

## Что прислал сервер

- Фича **`options`** в `/api/sync` и `/api/me`: у вопроса автоматики («Подскажи») бывает **`payload.options`** — 2–4
  варианта ответа `{label, поля payload…}` или `{label, reject: true}`. Ответ — **`suggestion.decide` с `option`**
  (номер варианта, с нуля); сервер сам кладёт вариант поверх payload и применяет, как «Да», а `reject` отклоняет с
  причиной `label`. Контракт — `server/contract/dela-crm.json` (правило про ответы кнопками).
- Вид **`/api/view/when?q=<фраза>&local=1&date=1`** (`server/pravka_dela/when.py`): фраза «завтра в 11», «в пятницу
  вечером», «через 2 часа», «когда приеду на дачу» → `{ok, set: {due_date, due_time, remind_at, remind_place}, words}`;
  `local=1` — только свой разбор сервера (без модели, мгновенно), без него непонятое уходит в Claude (Sonnet, по
  Enter); `date=1` — нужен только день. `ok: false` с `need_model` — «сам не понял», с `error` — словами.
- **`/api/ask`** со `scope.card = "task"` и `scope.open` — Claude видит только это дело; `scope.kstati` — мысль вдогонку
  (Claude сам решает: дописать к делу, завести рядом, записать факт клиенту). `scope.history` — разговор (до 13.10
  сервер его терял).
- **Направление по «Зачем»** — правило сервера (`store._krug_own`): при смене «Зачем» без направлений в той же
  операции прежнее своё главное уходит. Телефону ничего слать по-новому не надо — после синка `dirs` уже верные.
- **`settings.feed_hidden`** — id дел, которые владелец убрал из «Добавлено автоматически» крестиком (общая настройка
  человека, `user.settings`).

## Что сделать на телефоне

1. «Подскажи»: есть `payload.options` и сервер знает `options` — вместо «Да / Не надо» кнопки с `label` (первая —
   основная, `reject` — тихая красная); нажал — `suggestion.decide` с `option`, строка уходит. Нет вариантов — как
   было.
2. «Уточнить» (kind `update`, не Круг): «Да, согласен» и «Сам допишу» — поле; текст дописывается в заметку дела
   (`task.set notes`), предложение — `reject` с причиной `сам: <текст>`; пусто — просто «не надо».
3. «Поставил» → **«Добавлено автоматически»**; крестик у строки — убрать её из списка (`feed_hidden`), дело не
   трогать.
4. Карточка дела: срок и напоминание — **одна строка «Когда»** словами через `/api/view/when` (пока печатаешь —
   `local=1`, по «Готово» — без него), как понято — под строкой до сохранения, подсказки — только «Сегодня» и
   «Завтра». Поля даты и отдельного блока напоминания нет. «Напомнить ему» — та же строка с `date=1`.
5. Карточка дела: строка Claude «Что поправить в этом деле?» и «Кстати» (`/api/ask`, `card: task`); ответ — как у
   строки Claude на телефоне, с «Вернуть».
6. Карточка дела: «Проект» у дела без проекта ЗФ, висящего на цели, — эта цель (или её проект) с подписью «по
   дереву»; выбрать проект ЗФ руками можно. «Метки» в карточке не показывать (данные не трогать). Главное
   направление по цели — с пометкой «по цели», щелчком не снимается.

## Проверка

Тест на разбор `payload.options` (кривое — без кнопок), на `decide` с `option` и на «Сам допишу»; живая проверка — у
владельца: вопрос разборщика Круга в «Подскажи» с двумя кнопками-направлениями.
