## Что поменялось на сервере

- **Кандидаты — предложения** (`tasks.suggestions`, поле `suggestions` синка) с `source = "plan"`, `batch_ref =
  "plan:<YYYY-MM-DD>"` (день, НА который), `batch_title` («Сейчас на пт 16.10 · встреч ~3 — возьми 3»), `expires_at` —
  тот день, 12:00 по Москве. `payload`: `basket` (krug, carry, owed, deal, nudge), `for_date`, `focus_on` (= `for_date`),
  `why` и `from` (строки словами — показывать как есть, через « · »), `order` (место на экране, 1…), `ask` (фраза для
  клиентов без блока), `options`. У `kind = update` — `task_id` (дело есть); у `kind = create` — `title`, `project_id`,
  `deal_id`, `ball`, у «напомнить троим» — `nudge_ids`. Пример — `dela-plan.json`, `suggestion.example_update`.
- **Варианты** (`payload.options`, фича `options`, которая уже есть): `{label: "☆ На завтра" (Пт — "☆ На понедельник"),
  focus_on}`, у корзин owed и carry — `{label: "✓ Уже сделал", done: true}`, `{label: "Не надо", reject: true, reason:
  "план: не надо"}`. Ответ — `suggestion.decide` с `option` (как `AskRow` этапа 2). «✓ Уже сделал» сервер закрывает дело
  (status done, `focus_on` не ставит) — только у `source = plan`. Шестое на день — `ok: false` и слова «в «Сейчас» на пт
  16.10 уже пять дел: … — сначала убери одно»: показать как есть.
- **`focus_on` бывает будущей датой** — отмечено заранее. Правило «Сейчас» (`DelaGroups.isNow`: `focusOn == today`) НЕ
  меняется: такое дело встанет в «Сейчас» само в свой день. Предел пяти сервер держит на каждый день; телефонный
  `NOW_FULL` до запроса — только про сегодня (как и было), для дня плана — считать дела с `focusOn == for_date`.
- **Флаг** `plan` в `features` синка и `/api/me`. Нет флага — блока нет (кандидатов старый сервер и не кладёт).
- **Вид** `GET /api/view/plan` — шапка блока (владельцу): `for_date`, `label`, `offered`, `pending`, `marked`,
  `meetings`, `take`, `today {done, total}`, `stuck [{id, num, title, days}]`, `stats`. Телефону он не обязателен: всё,
  кроме «встреч ~N» и «сегодня сделано x из y», считается из снимка синка.

## Что сделать на телефоне

1. **`core/DelaViews.kt`**:
   - `mark("plan")` — значок `bolt`, подпись «план на завтра» (источник кандидата);
   - `plan(s, me, today)` — ждущие кандидаты плана (`source == "plan"`, `pending`, свои) по `payload.order`; `forDate` —
     `payload.for_date` первого (нет кандидатов — `null`); `marked` — свои открытые дела не-цели с `focusOn == forDate`;
     `label` — «на завтра» / «на понедельник» / «на сегодня, до 12:00» (как `planWhen` веба);

   В `overlay` (`suggestion.decide` с `option`) можно сразу показать результат: вариант с `focus_on` — `focusOn` дела,
   вариант с `done: true` у `source == "plan"` — дело сделано; иначе дело догонит синк.
