# Дела на телефоне — задание 14 (13.10.2026): Круг жизни 7.2 — дерево жизни, цели-узлы, место дела в дереве

подразделяются на цели, которые я ставлю, а дальше все дела идут в эти цели». И: «помимо круга жизни — вид „дерево
жизни“, когда всё это разделяется: девять колонок со списками, или просто список с фильтрами, или список, где
плюсиками раскрывается каждая — и ты так ходишь до каждого дела. В каждом деле тоже должно быть это дерево и его место
в нём: чтобы я понимал, зачем я это делаю и что будет дальше, когда я это сделаю».

## Модель — что прислал сервер

- Фича **`tree`** в `/api/sync` и `/api/me` (рядом с `krug`): только увидев её, телефон шлёт новые поля (иначе сервер
  отверг бы операцию целиком).
- У дела в синке (только у своих) новые поля: **`goal`** — дело стало целью, узлом дерева (цель — состояние, к
  которому идут: «сын хорошо знает математику»); **`rhythm`** — ритм практики словами («ежедневно», «2 раза в
  неделю»; цель с ритмом — практика: повторяется, не закрывается); **`no_steps`** — под целью дел не заводят
  (ориентир, а не задача). У цели всегда нет проекта: её текст видит только хозяин.
- В списке синка **`krug`** у проекта теперь и **`why_id`** — цель, на которой проект висит («клиентские проекты
  вешаются на цель целиком»): `[{id, kind: "project", directions, why_id, seq}]`. Хранить вместе с направлениями
  (сейчас `Snapshot.krug` — `Map<String, List<String>>`; нужен `{directions, whyId}`), на диске тоже.
- Справочник `krug.directions` в Своде теперь девять направлений: `{key, pos (0…8, место на круге: 0 — сверху,
  дальше через 40° по часовой), angle, zone ("Я" | "Мир" | "Семья"), name, short, formula, meaning, includes,
  excludes, examples, aliases}`. Порядок — по `pos`.
- Операции: `task.create` / `task.set` принимают **`goal`** (true — сделать целью: сервер сам уберёт проект; false —
  снова дело), **`rhythm`** (строка или пусто; ритм сам делает целью), **`no_steps`**; `why_title` теперь заводит
  цель-узел (без проекта, в главном направлении дела). `project.set` — **`why_id`** (повесить проект на цель).
  Сервер отказывает: проект у цели («цель живёт без проекта»), шаг под `no_steps`, «Зачем» по кругу.

## Правила (как веб и сервер)

- **Главное направление дела** — у корня цепочки «Зачем»: идём вверх по `whyId`; у звена без «Зачем» (кроме целей) —
  его проект (строка Круга проекта) и дальше цель проекта. Главное — первое направление самого верхнего звена, у
  которого направления есть. Свои направления дела, кроме главного, — **метки** (до двух). Итог: `[главное, метки…]`
  (до трёх). В 7.1 свои были сильнее наследованных — теперь своё под целью становится меткой.
- **Движение** — только в главном направлении; закрытая цель (узел или дело, у которого были шаги) — 3, дело — 1.
- **Цели — не дела**: их нет ни в одном списке дел («Сегодня», «Моё», «Все дела», фильтры, «Сейчас», счётчики).
  Они живут в дереве, в цепочке «Зачем» и в поиске.
- **«Моё»** — как было, но цели в него не попадают.
- **Место дела в дереве** (ключ родителя): «Зачем» (если цель открыта) → проект дела, если у проекта есть строка
  Круга (не у целей) → главное направление («без зачем») → «без направления».

## Что сделать

1. **Модель** (`core/Dela.kt`): поля `goal`, `rhythm`, `noSteps`; `FEATURE_TREE`; `EDITABLE` + `goal`, `rhythm`,
   `no_steps` (шлём только при фиче `tree`); `Snapshot.krug` — направления и `whyId` проекта (синк, диск, merge);
   `project.set` с `why_id`.
2. **Ядро** (`core/DelaKrug.kt`): `upOf`, `dirsOf` по правилу выше, `goalPath` («Здоровье › Еда › Белок 140+»),
   `movement` (главное, цели ×3), `mine` (без целей), `treeModel` (дети узла: цели по номеру, проекты по имени, дела по
   времени; открытых под узлом; движения под узлом за 7 дней), `belowOf` (что ниже по «Зачем» — туда не вешать).
   `DelaViews`: цели исключить из всех списков дел.
3. **Вкладка «Дерево жизни»** (после «Круг жизни», только при `krugOn` и фиче `tree`), три вида переключателем
   сверху (помнить выбор), фильтр направления:
   - **Дерево** — направление › цели › подцели › проекты › дела, плюсиком/минусом раскрывается каждая ветка
     (с завода направления и цели раскрыты, проекты свёрнуты; помнить); у цели — ромб (у практики — ромб-кольцо и
     ритм), число открытых дел под ней, «+N» движения за неделю, «пусто» у пустой; тап по цели — её карточка; дело —
     обычной строкой с отступом; проект — строкой с числом и раскрытием. Кнопки «Раскрыть всё» / «Свернуть всё».
   - **Колонки** — девять колонок рядом (горизонтальная прокрутка, колонка ~280dp, внутри — своя вертикальная), в
     шапке зона, название, открыто; внутри то же дерево компактно (цели, проекты, дела одной строкой с кружком).
   - **Список** — открытые дела (без целей) плоско, сортировка по пути; фильтры: направление, цель (лист с поиском
     по путям; дела под ней на любой глубине), «Без зачем» (нет цели в цепочке); у строки — путь курсивом.
   - **Перенос**: на телефоне вместо перетаскивания — долгий тап по делу, цели или проекту → лист «Куда повесить»
     (цели с путями и поиском, сверху — направления «прямо на направление»; проект — только на цель). Сервер сам
     откажет «по кругу» и под `no_steps`, текст отказа — тостом.
4. **«Круг жизни»** — обзор: принцип дня; циферблат (Canvas: девять осей через 40°, Здоровье сверху, кольца, подписи
   `short`; на конце оси — точка движения радиусом по `min(10, 3·√N)`; тап по подписи — дерево этого направления);
   ниже по зонам («Я», «Мир», «Семья») карточки направлений: название, открыто, «за неделю N», формула курсивом, цели
   верхнего уровня (тап — карточка цели). Внизу — «Без направления».
5. **Карточка дела**: сразу под названием — блок **«Место в дереве»**: направление (мелко, капслоком) › цели лесенкой
   (тап — карточка цели; проект — ▣ с переходом) › само дело (жирно) — под ним его шаги, рядом соседние шаги той же
   цели; ниже строка **«дальше»** (тексты — как `placeBlock` веба: «Сделаешь — к цели «…» останется N шагов» / «Это
   последний открытый шаг к цели «…» — дальше «…»» / у цели — «Под целью N подцелей и M шагов — а сама она ведёт к «…»», пустая — «Пустая цель
   — сигнал…» / «Висит прямо на направлении — «без зачем»…»). В свойствах: «Зачем» — кнопка «Повесить на цель /
   Поменять цель» (лист как выше + «Новая цель: «…»» по набранному, «Убрать «Зачем»»), «Сделать целью / Цель»
   (если у дела проект — подтвердить: «Цель живёт без проекта — её видишь только ты»), у цели — поле «Ритм»; у цели
   вместо проекта — «цель живёт без проекта — её видишь только ты»; направления — чипами (свои = метки, подпись
   «главное — у корня цепочки «Зачем», остальные — метки»); «Новый шаг к этой цели / к этому делу» — Enter заводит
   дело с этим «Зачем» (у цели — без проекта, у дела — в его проекте).
6. **«Подскажи» разборщика** (`source: krug`): у вопроса теперь `payload.why_id` и `payload.goal_path` (цель, которую

7. **Строка дела**: у цели (там, где она видна — дерево, поиск) — «цель · N шагов» или «практика · ритм».
