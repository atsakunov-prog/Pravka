# Задача: Правка 4.0 — пересобрать дизайн приложения

## Что сделать

Перестроить экраны Android-приложения «Правка» (Jetpack Compose, Material 3) по новому дизайну.

- **Главный экран — «Сегодня»:** хроника одного дня, где лента Засечки соединена с отметками всех режимов и продолжается в будущее.
- **Режимы становятся линзами** на этот день. Нижняя навигация уходит.
- **Разложенный телефон** получает настоящие двухколоночные раскладки.

Правила — в `DESIGN.md` рядом с этим файлом, он главный. Как должно выглядеть — `screens/`. Точные значения — `mockups/*.html`: это CSS, 1 px = 1 dp, размер шрифта px = sp. Если `DESIGN.md` и макет расходятся, прав `DESIGN.md`. Расхождение запиши в отчёт.

## Нельзя трогать

1. **Слой поверх других приложений.** Плавающие кнопки П, З, Д, ₽ и шестерёнка (док, стопка, веер), пилюля диктовки (слушаю, итог, вопрос), плашки с «ОК» и отсчётом, меню долгого нажатия. Их код, ресурсы, цвета, буквы, поведение — без изменений. Образец: `screens/00-overlays-ne-menyat.jpg`. Векторы букв и материал можно **переиспользовать** в приложении (монеты), но не менять исходники.
2. **Цвета режимов:** `#EA580C #F78810 #2A5D82 #2F6B4F #5E7A1F #5B4A8C`. Новых цветов режимов нет.
3. **Данные и их хранение.** Редизайн не меняет схемы баз, форматы синка с домашним сервером, промпты Claude. Если для экрана нужны новые данные — раздел «Данные» ниже.
4. **Сборка:** без сторонних библиотек (только Compose, Material 3, AndroidX), без R8.

## Запреты по виду

Светлая тема, эмодзи в кнопках, подчёркивания под заголовками, пульсация, мигание и дрожание, знаки режимов на фоне, абзацы-пояснения на экране (только за «i»), серые «грязные» плашки, размытие фона.

## Порядок работы

Делай по этапам. После каждого этапа приложение собирается и запускается; маленькие осмысленные коммиты на русском. Этапы 0–2 обязательны до экранов.

### Этап 0. Разведка и план
1. Прочитай `ui/Kit.kt`, тему, навигацию, модуль оверлея, экраны всех вкладок.
2. Составь соответствие: какая деталь набора есть → во что превращается по `DESIGN.md` §11 → какие детали новые → какие уходят (§11.8).
3. Проверь источники данных для «Сегодня» (раздел «Данные»): что уже есть, чего нет.
4. Запиши всё в `docs/redesign-4-plan.md`. Код на этом этапе не меняй, кроме самого файла плана.

### Этап 1. Тема и токены
- `PravkaTheme` — только тёмная; `ModeColors` и `LocalMode` (§4, §14); шкалы для графиков; цвета категорий Засечки (§4.3); состояния (§4.4).
- Шрифты Literata и Golos Text (OFL) — TTF в `res/font`, без загрузки из сети; `Typography` по §5 с `tnum`.
- Утилиты форматирования: тысячи через U+202F, минус U+2212, «1 ч 40 м», «пн, 5 октября».

### Этап 2. Набор деталей
- Всё из `DESIGN.md` §11, со всеми состояниями. Новая деталь сначала попадает в набор, потом на экран.
- Сделай отладочный экран «Витрина»: доступен из «Ещё → Служебное» только в debug-сборке. На нём все детали во всех состояниях для каждого режима, плюс `@Preview` для каждой детали.
- Сверь стекло, клавиши, монеты и плашки режимов с `screens/` — материал должен рифмоваться с оверлеем.

### Этап 3. Навигация
- Стартовый экран — «Сегодня».
- Убрать нижнюю навигацию из 7 кнопок и боковую колонку разворота.
- Входы в режимы: плашки режимов, пилюля «+84», отметки в ленте, «С» → Ещё, плавающие кнопки.
- «Назад» из любого режима → «Сегодня». Служебные экраны — стопкой поверх.
- Глубокие переходы: тап по отметке открывает режим на этой записи. Как сейчас открываются экраны из оверлея — сохранить.

### Этап 4. «Сегодня» на сложенном
- `screens/01`, `02`, `03`; `DESIGN.md` §12.1 и §11.2–11.5.
- Хроника как `LazyColumn` с sealed-типами строк. Открывается на «сейчас»; при прокрутке сжимается шапка; появляется кнопка «↓ сейчас».
- Все действия из §11.5: тап, долгое нажатие, «Записать», отметка дела.

### Этап 5. Засечка
`screens/04`, §12.3: циферблат, плашка времени, лента Засечки, итоги по категориям, телефон, SayBar со «стоп».

### Этап 6. Остальные режимы
Правка, Дела (Утро, Предстоящее, Новое, Жду, Неделя, Входящие, Все), Спорт (Сегодня, Путь, Журнал), Еда, Деньги (Сводка, Журнал) — по §12.4–12.8.

- Содержимое вкладок сохраняется — всё, что сейчас есть на экранах, остаётся. Меняются вид, порядок и детали набора.
- Пилюля ввода сверху заменяется на SayBar внизу.
- **Макеты режимов:** Дела `screens/06`–`08`, Спорт `09`, Еда `10`, Деньги `11`, Правка `12`, лист записи `13`. Остальные вкладки режимов (Дела · Жду / Неделя…, Спорт · Путь / Журнал, Деньги · Журнал) — по тексту §12 и образцу соседних.
- **Контрольная точка.** Сначала сделай один экран целиком — Дела · Утро, сложенный и разложенный, по `06` и `08`. Сними скриншоты в `docs/redesign-4-shots/`, остановись и покажи владельцу. Остальные режимы — после его ответа.

### Этап 7. Общая статистика, Ещё, Настройки, листы
§12.9–12.12. Новые пункты настроек: время сна, город погоды, календари, отметки на «Сегодня».

### Этап 8. Разворот
§12.2, §13 и раздел «Разворот» у каждого экрана. При ширине ≥ 600 dp — две колонки, деталь справа вместо листа. Растянутая одна колонка не допускается.

### Этап 9. Состояния везде
§12.13 для каждого экрана: пусто, загрузка, Claude думает, ошибка с причиной целиком, нет связи, прошлый и будущий день.

### Этап 10. Проверка и отчёт
1. Сними скриншоты своих экранов на 411×900 и 791×820 dp — через эмулятор Pixel 10 Pro Fold или `@Preview` с этими размерами. Положи в `docs/redesign-4-shots/`.
2. Сравни с `screens/` попарно. Пройди чек-лист приёмки.
3. Напиши `docs/redesign-4-report.md`:
   - что сделано;
   - что отличается от макета и почему;
   - какие данные не нашлись;
   - какие детали набора изменились, какие появились, какие ушли.

## Данные для «Сегодня»

Сначала проверь, что уже есть в приложении и на домашнем сервере. Данные не выдумывай: если источника нет, блок не показывается (или показывает «—»), а в плане и отчёте это отмечено.

| Что | Откуда |
|---|---|
| Записи Засечки за день, очки, категории | есть |
| Еда: приёмы со временем и ккал; ждущие подтверждения | есть |
| Деньги: операции за день со временем | есть |
| Спорт: сделанные и запланированные тренировки (intervals.icu), готовность | есть |
| Дела на сегодня: порядок, оценка минут; события «из встречи / из почты / сделано» со временем | есть, проверить наличие времени у событий |
| Календарь на сегодня | `CalendarContract` с разрешением READ_CALENDAR, без библиотек; выбор календарей в настройках |
| Погода: утро, день, вечер, осадки | если источника нет — Open-Meteo через `HttpURLConnection`, без ключа; город из настроек переводится в координаты один раз через geocoding API Open-Meteo; кэш прогноза 1 час; без сети ряд скрывается |
| Время сна | новая настройка, по умолчанию 23:30; отсюда «до сна» и «дела не влезают на N м» |
| Цель ккал | есть в Еде; для полосы на плашке |
| Дневной лимит денег | если месячного бюджета нет — новая настройка; без неё полоса на плашке Деньги не рисуется |

**Сборка хроники.** Один use-case собирает из всех источников список `DayItem`:

- записи Засечки — основа ленты;
- отметки других режимов прикрепляются к записи Засечки, в чей интервал попадает их время;
- после «сейчас» идут: свободные окна, календарь, планы тренировок, очередь дел по правилу `DESIGN.md` §11.5 (TaskRow), сон.

Балл дня, обрезка сна по полуночи и округление будущего — `DESIGN.md` §11.5 и §3.10.

## Приёмка

- [ ] Оверлей (кнопки, пилюля, плашки, меню) не изменён: diff по его модулю и ресурсам пуст.
- [ ] Ни одной светлой поверхности; тема не зависит от системной.
- [ ] Внутри режима нет чужих цветов; на «Сегодня» и в статистике цвета режимов — только как метки источника.
- [ ] Нижней навигации и боковой колонки нет; «назад» из режима ведёт на «Сегодня».
- [ ] «Сегодня» на 411×900 совпадает с `screens/01` по составу и порядку: шапка с «+84», погода, четыре плашки, хроника с «сейчас», будущее до сна, строка «сказать».
- [ ] Прокрутка: шапка сжимается в строку с пятью мини-плашками, есть «↓ сейчас», под шапкой нет резкой полосы.
- [ ] Засечка: циферблат по геометрии §12.3, плашка времени, итоги, телефон.
- [ ] Дела, Спорт, Еда, Деньги, Правка и лист записи совпадают с `screens/06`–`13` по составу и порядку блоков.
- [ ] Разворот 791×820: все главные экраны в две колонки; сложенный боком (900×411) — одна колонка.
- [ ] Монеты Т и Е нарисованы в стиле П, З, Д; векторы оверлея не изменены.
- [ ] Главное действие каждого экрана — внизу справа, все цели ≥ 48 dp.
- [ ] Числа моноширинные; «1 074 898» и «Передвижение: транспорт» помещаются; минус — U+2212.
- [ ] Пояснений абзацами на экранах нет, только «i».
- [ ] Ничего не пульсирует и не мигает; свет режима плывёт медленно.
- [ ] Состояния §12.13 есть на каждом экране.
- [ ] Витрина набора есть в debug-сборке.
- [ ] Сборка без сторонних библиотек и без R8; приложение собирается и запускается после каждого этапа.
