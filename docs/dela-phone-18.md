## Что прислал сервер

- `POST /api/ask`: `scope.talk_id` — номер разговора (любая строка до 64 знаков: буквы, цифры, «-», «_»). Экран
  разговора сервер запоминает по нему на полчаса: следующая реплика того же разговора читает голову из кэша
  (замер 13.10: $0,19 первая реплика, $0,016 следующая). `scope.history` — прошлые реплики (до 13.10 сервер их терял).
- Ответ: **`refs`** — дела, о которых ответ (`[{id, num, title}]`, по порядку важности): показать ссылками под ответом.
- Модель — одна на всех, дорога `talk` (Свод `models.dela`); `claude_model` и `claude_effort` в настройках человека
  сервер больше не читает. `/api/settings` отдаёт `routes` — что сейчас стоит (для подписи).
- В карточке клиента, сделки и человека Claude видит и последние встречи с договорённостями.
