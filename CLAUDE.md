# Правка — карта для сессии

Личное Android-приложение одного владельца: Kotlin, Compose, один APK. Диктовка в
любое поле (Правка), таймшит (Засечка), дела в Todoist (Дела и Разноска), спорт
и еда (Тело). Один движок слушает все диктовки и ходит в Claude; режимы живут
вокруг него. Код и документация — по-русски, комментарии объясняют ПОЧЕМУ.

## Как читать репозиторий (это главное)

Не читай README и код целиком. Сессия на «одну кнопку» должна прочитать ОДИН
документ режима и файлы из его раздела «Файлы режима» — обычно три-пять.

| Задача касается | Прочитать сначала |
|---|---|
| Правка текста, кнопка «П», словарь, правила, обучение, эвалы | `docs/pravka.md` |
| Засечка: лента, категории, телефон по дням, автопилот, NFC, Sheets, напоминания | `docs/zasechka.md` |
| Дела и Разноска: Todoist, кнопка «Д» | `docs/dela.md` |
| Тело: план дня, силовые, зарядка, светофор, intervals, Notion (план, справочник, Дневник) | `docs/telo.md` |
| Еда: КБЖУ, дневник, рацион, wellness | `docs/eda.md` |
| Разборы: паттерны, дайджесты, CSV всей жизни, структура и синк жизни в Notion | `docs/razbory.md` |
| Служба, плавающие кнопки, самообновление, настройки, хранение | `docs/build.md`, `docs/data.md`, раздел «Движок» ниже |
| Деление на модули, что где лежит и почему | `docs/architecture.md` |

Перед правкой ленты (`ZasechkaStore`), службы доступности, промптов или любой
записи в Notion и intervals — открой `docs/agreements.md`: там причины, по
которым код такой, какой есть, с реальными случаями. Ниже — только выжимка.

## Движок (общее для всех режимов, читать по необходимости)

- **Диктовка:** `provider/GoogleSpeechSession.kt`, `provider/WhisperProvider.kt`
  (+ `WhisperNative.kt`), `data/Recordings.kt`, `data/WavFile.kt`,
  `data/LiveDraft.kt`, `trigger/DictationService.kt`, `core/VoiceCommands.kt`.
- **Claude:** `provider/ClaudeProvider.kt` — только транспорт (HTTP, SSE-стрим,
  кэш промпта, ретраи, деньги через `Pricing.kt`, форма запроса по модели и
  усилию — `RequestPolicy.kt`) плюс Правка (чистка, обучение). Какая модель и
  с каким усилием на какой дороге — `data/ModelRoutes.kt` (каталог дорог и
  заводские) и `settings.modelChoice(ModelRoute.X)`; владелец меняет это в
  настройках, группа «Модели» (`ModelsSettings.kt`).
  Разборы режимов — расширения того же класса рядом: `ClaudeZasechka.kt`,
  `ClaudeRaznoska.kt`, `ClaudeFood.kt`, `ClaudeBody.kt`, `ClaudeAnalysis.kt`.
  Контракты (`ClaudeProvider.XxxParse`) остаются вложенными в главный класс.
- **Промпты:** `core/Prompts.kt` — индекс и `assemble()`; тексты по режимам в
  `core/prompts/Prompts<Режим>.kt`. Владелец правит промпты на телефоне
  (`data/PromptStore.kt`), заводские тексты — запас.
- **Словарь, правила, обучение:** `data/DictionaryStore.kt`, `data/RulesStore.kt`,
  `data/LearnStore.kt`, `data/EditWatchStore.kt`, `core/ProofreadEngine.kt`.
- **Хранение и обвязка:** `data/StoreFiles.kt` (атомарная запись, `.prev`,
  `.corrupt`), `data/DiskWriter.kt`, `data/Backups.kt`, `data/Settings.kt`,
  `data/ModelRoutes.kt`, `data/EventLog.kt`, `data/Stats.kt`, `data/Updates.kt`,
  `ui/*`.
- **Служба доступности:** `trigger/PravkaAccessibilityService.kt` — хозяин
  микрофона, оверлейных окон, стопки кнопок и тиков. Режимные куски — расширения
  рядом: `trigger/ServiceZasechka.kt`, `ServiceRaznoska.kt`, `ServiceBody.kt`,
  `ServiceAnalysis.kt`. Сами кнопки — `*ButtonController.kt`.
- **Сборка приложения:** `PravkaApp.kt` (сервис-локатор: все сторы и движки),
  `MainActivity.kt` (вкладки), `SettingsTab.kt` (группы настроек),
  `ModelsSettings.kt` (группа «Модели»).

## Сборка и проверка

```bash
./gradlew compileDebugKotlin -PbuildNumber=999   # компиляция без сборки APK
./gradlew testDebugUnitTest -PbuildNumber=999    # JVM-тесты (app/src/test)
./gradlew assembleDebug                          # APK
```

В облачной сессии: SDK ставится в `/opt/android-sdk`, путь — в
`local.properties` (`sdk.dir=…`, файл не в git), Gradle есть в `/opt`. Перед
пушем — компиляция и тесты обязательны; новый случай разбора — сначала тест.

CI (`.github/workflows/build-apk.yml`) собирает APK на каждый пуш в любую ветку
и форс-пушит его в `apk-builds`. **Телефон обновляется сам только из своей
линии — `claude/parallel-tracks-timesheets-4s8zvc`.** Все рабочие ветки сведены
в одну точку; новая работа — своей веткой от неё, потом fast-forward всех
перечисленных в `docs/build.md`, линию телефона пушить ПОСЛЕДНЕЙ. PR не открывать
без явной просьбы. Коммиты: тема по-русски, дальше причины, как в истории.

## Железные правила (выжимка `docs/agreements.md`)

1. **Лента и дневник еды — незаменимые данные.** Пустой список поверх файла не
   записывается; миграции пишут только после чтения; сырая надиктовка не
   удаляется никогда. Кэш спорта и плана — расходный, но пустой ответ API в
   него не пишется.
2. **Складывание Fold — больная тема.** Ничего тяжёлого на главном потоке
   службы; окна не прятать через `GONE`, а снимать из WindowManager; за чужими
   окнами не подглядывать; на оконные события не подписываться.
3. **Внизу ровно шесть кнопок, плавающих ровно четыре (П · З · Д · Т).** Новая
   вкладка — в `SERVICE_TABS` под «Ещё». Настройки — в одной вкладке по группам
   режимов, composable группы живёт в файле своего режима.
4. **Еда ленту не отращивает** — только `ZasechkaStore.annotate`.
5. **Наружу пишем осторожно.** В Notion — только «Дневник» (свои колонки) и базы
   «Правка: разборы» по схеме `core/NotionLifeSchema.kt` (структура живёт в
   коде, приложение достраивает её само); в intervals не PUT-ить, не прочитав;
   наш блок в описании — между маркерами `[Правка]…[/Правка]`, идемпотентно.
   Параллельного трека в ленте нет: телефон считается по дням.
6. **Ошибку не затирать общей фразой**, HTTP-причина доходит до владельца целой.
   Молчаливая механика читается как поломка: отложенная дорога наружу называет
   состояние словами и даёт кнопку подтолкнуть.
7. **Модель и усилие — настройка владельца, не константа.** Каждый вызов
   Claude читает `settings.modelChoice(ModelRoute.X)`; дороги и заводские —
   `data/ModelRoutes.kt`. Заводские: разборы Засечки, Тела и Еды — Опус со
   стабильным префиксом под часовым кэшем (словарь `{DICT}` — в переменном
   хвосте), правка текста и подсказки тренера — Сонет, сверка паттернов —
   Fable 5.1. `thinking: disabled` — только Сонету и только до high
   (`RequestPolicy`): Опусу с xhigh/max и Fable явное «disabled» — это 400.
8. **Подпись — только `keystore/pravka.jks`.** Прокси на VPS не делаем. Своей
   камеры не открываем (системный интент и сканер Play Services).
9. **intervals.icu:** поля `fatTotal` и `icu_rpe`; `optString` у JSON null
   отдаёт строку «null» — читать через `IcuSportSync.text(o, key)`.
10. **Строка плана — один парсер** `core/PlanLine.kt` (вкладка, отчёт зарядки,
    досыл в intervals). «Турник» — не зарядка; зарядка узнаётся по тегу или слову.
11. **Спецификация живёт в `docs/`.** Изменил поведение — поправь документ
    режима; новая договорённость — в `docs/agreements.md`; закрыл этап —
    `docs/status.md`. README — только карта.
