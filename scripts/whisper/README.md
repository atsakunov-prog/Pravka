# Локальный Whisper для Правки

Маленькая модель под **диктовку**, загруженная в видеопамять один раз, и
OpenAI-совместимый эндпоинт поверх неё. Встречи по-прежнему разбирает
Telegram-бот своей моделью — этот сервис его не заменяет и не трогает.

Почему отдельный процесс, если модель у бота и так висит в памяти:

- **очередь**. Одна видеокарта считает по одной задаче. Пока бот разбирает
  часовую встречу, запрос диктовки ждал бы в очереди все эти минуты — а фразу
  надо вставить в поле сейчас;
- **размер**. Для фразы на пятнадцать секунд `large-v3` с лучом 5 — это
  стрельба из пушки: `large-v3-turbo` с лучом 1 отвечает заметно быстрее при
  почти том же качестве;
- **риск**. Рабочий конвейер расшифровок ломать ради диктовки не стоит.

Движок здесь `faster-whisper` (CTranslate2): веса те же, что у референсного
PyTorch-Whisper, но исполнение обычно в 3–5 раз быстрее и вдвое экономнее по
видеопамяти.

## Установка (Windows 11, PowerShell)

```powershell
cd scripts\whisper
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\pip.exe install -r requirements.txt
```

Первый запуск скачает веса с Hugging Face (turbo — около 1.6 ГБ) в
`%USERPROFILE%\.cache\huggingface`.

```powershell
.\run.ps1                                        # запуск в окне, видно лог
Invoke-RestMethod http://127.0.0.1:8178/health   # в другом окне
```

Автозапуск при входе в систему:

```powershell
.\install-service.ps1            # поставить
.\install-service.ps1 -Remove    # убрать
```

## Настройки

Всё в `whisper.env` рядом. Главное:

| Ключ | Смысл |
|---|---|
| `PRAVKA_WHISPER_MODEL` | модель по умолчанию; `large-v3-turbo` для диктовки |
| `PRAVKA_WHISPER_PRELOAD` | что загрузить сразу при старте (через запятую) |
| `PRAVKA_WHISPER_COMPUTE` | `int8_float16` — примерно 1,2 ГБ видеопамяти; `float16` быстрее, но около 2,3 ГБ |
| `PRAVKA_WHISPER_FALLBACK_DEVICE` | куда отступать, когда видеопамяти не хватило (`cpu`) |
| `PRAVKA_WHISPER_RETRY_GPU_MIN` | через сколько минут после отступления пробовать GPU снова |
| `PRAVKA_WHISPER_MAX_LOADED` | сколько моделей держать в памяти одновременно |
| `PRAVKA_WHISPER_HOST` | `127.0.0.1` — только этот компьютер. См. «Доступ с телефона» |

Модель и луч можно прислать в самом запросе (`model`, `beam_size`), так что
при желании этот же сервер разберёт и длинную запись точной моделью — но по
умолчанию он занят только диктовкой.

## Видеопамять: сервис уступает боту

На карте с 8 ГБ модель бота уже занимает большую часть. Расчёт под диктовку:
`large-v3-turbo` в `int8_float16` — около **1,2 ГБ** (против 2,3 ГБ у
`float16` и 4,7 ГБ у полной `large-v3`), одна модель в памяти, луч 1.

Если и этого не хватило — сервис **уступает, а не падает**:

- не смог загрузиться на GPU → грузится на процессор;
- память кончилась посреди распознавания → отдаёт видеопамять боту,
  дораспознаёт на процессоре и ближайшие 15 минут работает там же, потом
  снова пробует GPU (к этому времени встреча обычно уже разобрана).

На процессоре медленнее, но диктовка работает, а чужой разбор не ломается.
Что реально происходит, видно в логе сервера и в ответе `/health`: рядом с
моделью написано, на чём она сейчас считает.

Посмотреть, сколько памяти свободно: `nvidia-smi` в PowerShell.

## Как пользоваться руками

```powershell
# короткая запись
curl.exe -F file=@take.wav -F model=large-v3-turbo http://127.0.0.1:8178/v1/audio/transcriptions

# длинная запись точной моделью и лучом 5, ответ текстом. На карте с 8 ГБ
# сервис ради этого выгрузит диктовочную модель, а не поместит вторую рядом.
curl.exe -F file=@long.m4a -F model=large-v3 -F beam_size=5 -F response_format=text `
         http://127.0.0.1:8178/v1/audio/transcriptions
```

Параметр `prompt` — подсказка распознавателю: Правка кладёт туда слова из
своего словаря, и фамилии с терминами распознаются правильно сразу, без
последующей починки.

## Если не заводится

- **`Could not load library cudnn_ops64_9.dll`** — CTranslate2 не нашёл cuDNN.
  Он ставится вместе с зависимостями (`nvidia-cudnn-cu12`); если ставил
  зависимости без них, добавь:
  `.\.venv\Scripts\pip.exe install nvidia-cublas-cu12 nvidia-cudnn-cu12`.
- **Не хватает видеопамяти** — сервис уйдёт на процессор сам (см. выше). Если
  хочется вообще не трогать GPU, поставь `PRAVKA_WHISPER_DEVICE=cpu`; если
  наоборот, память есть — `PRAVKA_WHISPER_COMPUTE=float16` ускорит.
- **Нет GPU под рукой** — `PRAVKA_WHISPER_DEVICE=cpu` и
  `PRAVKA_WHISPER_COMPUTE=int8`. Медленно, но работает.
- **Модель `large-v3-turbo` не найдена** — старый `faster-whisper`. Обнови
  (`pip install -U faster-whisper`) или впиши в `PRAVKA_WHISPER_MODEL` полный
  идентификатор репозитория, например
  `mobiuslabsgmbh/faster-whisper-large-v3-turbo`.

## Доступ с телефона (по желанию)

Сервер слушает только `127.0.0.1`. Если захочется, чтобы телефон дома тоже
распознавал этой моделью вместо своей `small`, поставь
`PRAVKA_WHISPER_HOST=0.0.0.0` — и **только вместе** с ограничением доступа:
или правило брандмауэра на домашнюю сеть, или Tailscale. Открывать порт в
интернет нельзя: эндпоинт без пароля.
